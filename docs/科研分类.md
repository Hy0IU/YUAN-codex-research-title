# 科研对话分类

标题使用 `emoji 对象｜持续目标`。项目分组提供外层上下文；标题优先保留具体论文、方法、模块、数据集、实验变体或章节，不机械重复项目目录名。

| Emoji | 分类 | 适用内容 |
|---|---|---|
| 📚 | 文献与基线 | 文献检索、论文阅读、相关工作、基线来源与可比性 |
| 💡 | 问题与创新 | idea、研究问题、假设、创新点和贡献边界 |
| 🧠 | 方法与模型 | 理论机制、模型架构、模块关系、公式和方法命名 |
| 🧪 | 实验设计 | 数据集、指标、消融、对照、seed、超参数和统计检验方案 |
| 💻 | 代码与复现 | 实现、调试、训练/评估流程、环境和程序化绘图 |
| 📊 | 结果与证据 | 指标分析、跨 seed 稳健性、表图与正文一致性、证据审计 |
| ✍️ | 论文与审稿 | 论文结构、写作润色、模拟审稿、回复和修订 |
| 🎨 | 图表与汇报 | 图表视觉布局、方法图、PPT 和汇报呈现 |

## 容易混淆的边界

- 查证某基线的论文与代码：📚；把比较理由写入论文：✍️。
- 设计消融矩阵和控制变量：🧪；实现运行脚本：💻；分析结果能否支持主张：📊。
- 核对图表数字和正文结论：📊；修复图像裁切或调整布局：🎨；修改绘图程序：💻。
- 方法机制的解释和架构推理：🧠；研究方向与贡献判断：💡。

## 研究项目线索

插件只向命名模型提供简短标签，不传绝对路径：`My-Paper`、`MOE代码`、`MOE实验结果`、`MOE实验运行`、`My-Paper2`。这些标签用于去重和消歧，不作为固定标题前缀。结果话题在确实需要区分时使用数据集、实验变体、指标/划分或 seed 口径。

## 标题示例

- `📊 双轴结构消融｜核验 Fig. 3 与正文分析`
- `✍️ DLSP 与 MCMDRec｜补足相关工作比较理由`
- `🧪 双轴交互消融｜设计参数匹配的对照方案`
- `💻 NYC t-SNE 绘图脚本｜保存论文复绘坐标`
- `📊 PHO 消融｜核对验证集与多 seed 口径`
- `💡 Next-POI 超图推荐｜筛选有区分度的研究问题`
